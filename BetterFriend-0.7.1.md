# BetterFriend 0.7.1

- Replaces the formal feedback chooser with one simple **Tell Eric** path.
- Lets testers describe something weird, confusing, useful, or annoying in
  their own words; one sentence is enough.
- Keeps the privacy reminder short and keeps optional technical details tucked
  behind a disclosure.
- Renames the menu-bar feedback action and local dashboard tab to **Tell Eric**.
- Keeps **My people** as the optional shortcut list for up to ten people. It
  remains separate from Today recommendations, cadence, and reminders.

BetterFriend still never submits feedback itself. It opens a private GitHub
form only when you ask, and nothing is sent until you press Submit there.
