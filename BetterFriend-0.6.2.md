# BetterFriend 0.6.2

- Makes encrypted preference imports apply exactly what the preview showed.
- Prevents scans and preference transfers from overwriting each other's changes.
- Keeps automatic relationship suggestions from becoming manual choices on another Mac.
- Improves import previews, Undo, recovery, and encrypted export reliability.
- Strengthens privacy checks, release checks, and fictional-data testing.

BetterFriend still never sends messages for you. Relationship data and message
content are never attached to update checks.
