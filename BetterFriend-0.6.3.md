# BetterFriend 0.6.3

- Keeps setup available until the first successful scan, even after choosing
  Not now.
- Shows visible scan progress and distinguishes not scanned, missing Contacts,
  no local Messages history, recovered data, and genuinely caught up.
- Makes installation safe for both administrator and standard macOS accounts,
  preserving the previous app if replacement fails.
- Explains the standard-account administrator prompt, Messages sync, and the
  required relaunch in the first-run setup itself.
- Improves keyboard focus, disclosure controls, and native button target sizes.
- Adds a direct tester setup path and a privacy-safe Setup report.

BetterFriend still never sends messages for you. Relationship data and message
content are never attached to update checks.
