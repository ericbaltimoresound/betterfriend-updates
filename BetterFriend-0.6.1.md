# BetterFriend 0.6.1

- Adds the signed in-app update path and private feedback workflow.
- Reworks first-run setup, Privacy & Data, Start at Login, and full local reset.
- Replaces automatic plaintext profile sync with manual encrypted preference transfer.
- Improves first-day recommendations, automatic Tracks, and draft choices.
- Simplifies the dashboard toolbar and strengthens privacy and recovery checks.

BetterFriend still never sends messages for you. Relationship data and message
content are never attached to update checks.
